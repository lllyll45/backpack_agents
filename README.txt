Исправленная версия многоагентной системы распределения снаряжения.

Структура:
src/agents - исходный код Java
data/items.txt - исходные предметы (масса пробел название)
result/result.txt - создаётся менеджером после завершения

Важно:
1. Подключите JADE к classpath проекта.
2. Компилируйте пакет agents.
3. Запускайте Main без аргументов на серверном компьютере.
4. На клиентском компьютере запускайте Main с аргументами: <количество_туристов> client <IP_сервера>.
5. Путь data/items.txt должен быть доступен в рабочей директории сервера.

Протокол:
- туристы самостоятельно запрашивают сведения о рюкзаках и предлагают обмены;
- менеджер последовательно обрабатывает COMMIT_SWAP и проверяет, что общий разброс
  веса строго уменьшается;
- менеджер обновляет распределение и отправляет BAG_UPDATE;
- ItemAgent получает SET_OWNER от менеджера.

Ограничение этой версии:
начальное распределение создаётся менеджером жадным алгоритмом; автономность туристов
реализована на этапе поиска и согласования обменов. Для надёжной остановки в
распределённой среде желательно дополнительно ввести протокол завершения раунда
с подтверждениями от всех туристов.
