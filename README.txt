1. Требования
Перед запуском необходимо установить:
- Java JDK 25 или совместимую версию;
- IntelliJ IDEA Community Edition;
- JADE 4.6.0.(Файлик в lib, нажать add as library)

3. Запуск на одном компьютере
Для локальной проверки:
1. Запустить созданную конфигурацию в IntelliJ IDEA.
2. После запуска должен открыться графический интерфейс JADE.
3. В консоли появится сообщение о загрузке предметов и запуске менеджера.
4. Дождаться регистрации всех туристов.
5. Менеджер сформирует начальное распределение предметов.
6. Туристы начнут обмениваться предложениями, а менеджер будет проверять и подтверждать допустимые обмены.
7. После завершения планирования программа выведет итоговое распределение.
Пример команды запуска из PowerShell, если текущая директория — папка проекта:
java -cp "lib\jade.jar;out\production\backpack_agents_fixed" agents.Main 3


4. Запуск на двух компьютерах по локальной сети
Для демонстрации работы распределённых агентов можно использовать два компьютера, подключённых к одной локальной сети.

На первом компьютере (сервере):
1. Запустить серверную часть приложения.
2. Открыть графический интерфейс JADE.
3. Узнать локальный IP-адрес компьютера с помощью команды:
ipconfig


4. Найти IPv4-адрес активного сетевого адаптера, например 192.168.16.1.

На втором компьютере (клиенте):
1. Скопировать проект на второй компьютер.
2. Установить Java и настроить библиотеку JADE.(Файлик в lib, нажать add as library)
3. Открыть PowerShell в папке проекта.
4. Выполнить команду:
java -cp "lib\jade.jar;out\production\backpack_agents_fixed" agents.Main 2 client 192.168.16.1


Вместо 192.168.16.1 указать реальный IP-адрес первого компьютера.

Количество туристов, создаваемых на сервере и клиентах, должно соответствовать общему количеству, ожидаемому менеджером. Если подключение не устанавливается, необходимо проверить настройки брандмауэра Windows и доступность серверного компьютера по локальной сети.
5. Результат работы программы
После завершения распределения в консоли отображаются:
- начальное распределение предметов;
- масса рюкзака каждого туриста;
- информация о предложенных обменах;
- решения менеджера об одобрении или отклонении обменов;
- итоговое распределение предметов.
Результат работы также сохраняется в файле:
result/result.txt


В нём содержится итоговый план распределения снаряжения между туристами.
